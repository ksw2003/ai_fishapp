# 관상어용 스마트 어항 시스템
IOT+Node.js+AI 기반 어항 관리 시스템

## 프로젝트 소개
본 프로젝트는 IoT 기술과 AI를 활용하여 관상어 사육 환경을 효율적으로 관리할 수 있는 스마트 어항 시스템입니다. 센서를 통해 수온 및 수질 데이터를 수집하고, 모바일 애플리케이션을 통해 어항 상태를 실시간으로 확인할 수 있습니다. 또한 원격 환수 및 먹이 급여 기능과 AI 기반 어항 관리 챗봇을 제공하여 사용자가 보다 편리하게 관상어를 관리할 수 있도록 지원합니다.

## 🚀 Getting Started (실행 방법)

### 1. APK 파일을 이용한 설치

프로젝트에서 제공하는 APK 파일을 Android 스마트폰으로 다운로드합니다.
다운로드한 APK 파일을 실행합니다.
설치 과정에서 출처를 알 수 없는 앱 설치를 허용합니다. (필요한 경우)
설치가 완료되면 앱을 실행합니다.

### 2. 개발 환경에서 직접 실행
필요 환경
Flutter SDK
Android Studio 또는 Android SDK
Android 스마트폰 또는 에뮬레이터
실행 순서

# 1. 프로젝트 저장소 복제
git clone [저장소 주소]

# 2. 프로젝트 폴더로 이동
cd [프로젝트 폴더]

# 3. 필요한 패키지 설치
flutter pub get

# 4. 연결된 기기 확인
flutter devices

# 5. 애플리케이션 실행
flutter run

3. 실행 시 참고 사항

앱의 정상적인 기능 사용을 위해 백엔드 서버가 실행 중이어야 합니다.

서버와의 통신을 위해 앱의 API 서버 주소가 올바르게 설정되어 있어야 합니다.

환수 및 먹이 급여 제어 기능을 사용하려면 라즈베리 파이와 관련 하드웨어가 연결되어 있어야 합니다.
